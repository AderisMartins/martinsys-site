## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Build and deployment

- Site config (GitHub Pages project site) lives in `astro.config.mjs`: `site: 'https://aderismartins.github.io'`, `base: '/martinsys-site/'`.
- Build with `npm run build`; preview the output with `npm run preview`.
- Deploy runs via `.github/workflows/deploy.yml` on pushes to `main` (Astro action building `dist/` → GitHub Pages). Validate changes locally before pushing.
